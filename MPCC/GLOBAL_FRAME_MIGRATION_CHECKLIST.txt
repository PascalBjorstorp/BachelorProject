MPCC Global Frame Migration Checklist
======================================
Goal: Remove Frenet states (n, alpha) and move to 7-state Liniger MPCC
Old state [9]: [s, n, alpha, vx, vy, omega, X, Y, psi]
New state [7]: [s, vx, vy, omega, X, Y, psi]
Controls [3]: [delta, a_x, v_theta] (unchanged)

Contouring/lag errors use global (X, Y) + virtual parameter s (Liniger 2015).

FILE 2: src/mpcc_vehicle_model.c  (Dynamics Linearization)
================================================================================
[ ] Remove row 1 (dn/dt = vx*sin(alpha) + vy*cos(alpha))
[ ] Remove row 2 (dalpha/dt = omega - kappa * v_theta)
[ ] Remove all Frenet kinematic variables: sin_a, cos_a, v_proj, v_perp,
    dn_dalpha, dn_dvx, dn_dvy
[ ] New row layout for A (7x7) and B (7x3):
      Row 0 (s):     ds/dt = v_theta          → B[0][VTHETA] = dt
      Row 1 (vx):    dvx/dt = a_x + tire      → B[1][AX] = dt, tire Jacobians
      Row 2 (vy):    dvy/dt = tire - vx*omega  → tire Jacobians + delta coupling
      Row 3 (omega): domega/dt = tire moments  → tire Jacobians + delta coupling
      Row 4 (X):     dX/dt = vx*cos(psi) - vy*sin(psi)
      Row 5 (Y):     dY/dt = vx*sin(psi) + vy*cos(psi)
      Row 6 (psi):   dpsi/dt = omega
[ ] Update A matrix: I + dt*A_c (7x7)
[ ] Update B matrix: dt*B_c (7x3)
      B[0][VTHETA] = dt
      B[1][AX] = dt
      B[1][DELTA] = dt * (-dFyf_dd*sin(delta) - Fyf*cos(delta)) / m
      B[2][DELTA] = dt * (dFyf_dd*cos(delta) - Fyf*sin(delta)) / m
      B[3][DELTA] = dt * lf * (dFyf_dd*cos(delta) - Fyf*sin(delta)) / Iz
[ ] Update affine term d = f(z_bar, u_bar) - A*z_bar - B*u_bar
      z_next[0] = s + dt * v_theta
      z_next[1] = vx + dt * (a_x + (-Fyf*sin(delta))/m + vy*omega)
      z_next[2] = vy + dt * ((Fyf*cos(delta) + Fyr)/m - vx*omega)
      z_next[3] = omega + dt * (lf*Fyf*cos(delta) - lr*Fyr)/Iz
      z_next[4] = X + dt * (vx*cos(psi) - vy*sin(psi))
      z_next[5] = Y + dt * (vx*sin(psi) + vy*cos(psi))
      z_next[6] = psi + dt * omega
[ ] Update z_bar array in affine term from 9 to 7 elements
